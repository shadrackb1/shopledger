# ShopLedger

Retail ledger and inventory for small shops. Record sales and expenses, track stock, and export clean reports.

## What it does

- Sales and expense entry with customer records
- Product and inventory management
- Dashboard with weekly sales and statistics charts
- PDF report export (jsPDF)
- AI assistant for quick queries on shop data
- Auth-gated sessions with offline-friendly IndexedDB cache

## Stack

React 19, TypeScript, Vite, React Router, Recharts, Firebase, IndexedDB, jsPDF, Google Gemini.

## Run locally

```bash
npm install
npm run dev
```
